# grid-duel

- Read `docs/reference/PLAN.md` at the start of a session and work on one roadmap step at a time. If the plan and the code disagree, say so and ask.
- Rules source: `docs/reference/flockade-rules.md`, a frozen copy of the wiki page. The engine follows it. Do not refresh it from the wiki unless asked.
- Interpretations: `RULES.md` (created in step 1) lists every choice the wiki does not settle, each marked as an interpretation. When the wiki is silent or ambiguous, choose the simplest reading and record it there; when the user has answered a rules question, record the answer there too.
- Deliberate differences from the original (no Trickster+, no betting) are listed in PLAN.md section 3 and must be recorded in `RULES.md`.
